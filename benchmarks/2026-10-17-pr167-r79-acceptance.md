# PR #167 acceptance (r79): Q4_K VDR-4 for the MoE expert kernel, and the multi-GPU KV prefill pad default

Date: 2026-10-17.  Delivery: `v12-097cf33d9-r79` (12 blocks, tree
`c9ed11139a9a1e469bff18b037aef9cc1b0b2c93`).  Two changes are recorded here:

- **PR #167** (`@briansp2020`, `rdna3-mmvq-moe-q4k-vdr4`): the MoE expert kernel takes the 32-element dense
  Q4_K dot product (`vec_dot_q4_K_q8_1_vdr4_dense`) on RDNA3_0 by default, and on RDNA4 behind the
  build-time opt-in `-DGGML_HIP_RDNA4_Q4K_MOE_VDR4` (default off).
- **PR #168 follow-up**: `LLAMA_KV_N_PAD_PREFILL` is now default-on (**8192**) when more than one device is
  in use, and inactive on a single device.  The env value still overrides (`0` disables).

This file records the RDNA4/R9700 pass and an independent RDNA3/gfx1100 rerun.  It is a measurement
record, not the delivery policy; `WORKLOG.md` 261017.002 is the release entry.

## What the patch does

`mul_mat_vec_q_moe` used `vec_dot_q4_K_q8_1_vdr4`: one scale / convert / fma per 8-element chunk.
`vec_dot_q4_K_q8_1_vdr4_dense` has the same 32-element layout and VDR 4, but sums each sub-block's 16
products in one integer `dp4a` chain before the single scale / convert / fma.  The layout and the K-split
width are unchanged; only the summation order changes.  The selector is still width-uniform, and the
pinned fusion ops keep plain `calc_nwarps`.

The decoded text is identical on/off in every arm (MoE 35B-A3B, 31 k prompt, 32-token greedy,

noise and the explicit `=0` arm is the same build.  The default only activates when
`model.n_devices() > 1` or the meta split state has more than one device, so a single GPU is untouched.

  -ngl 99 -sm tensor -mg 0 -ctk q8_0 -ctv q8_0 -t 8 -p 512 -n 256 -r 5

  -ngl 99 -sm tensor -mg 0 -ctk q8_0 -ctv q8_0 -t 8 -c 8192 -b 512 -ub 512 \
  -npp 16 -ntg 32 -npl 1,4,8

# 4-axis MTP, gate length
HIP_VISIBLE_DEVICES=0,2 ./build/bin/llama-cli -m <35B-A3B-Q4_K_M> \
  -ngl 99 -sm tensor -mg 0 -ctk q8_0 -ctv q8_0 -t 8 -c 16384 -n 3000 \
  --temp 0 --seed 42 --single-turn --no-display-prompt --spec-type draft-mtp \
  --reasoning off -f ../llama-cpp-rdna-boosts/prompts/prose-rdna-boosts.txt

  -ngl 99 -sm tensor -mg 0 -ctk q8_0 -ctv q8_0 -t 8 -c 65536 -b 2048 -ub 2048 \
  -n 1 -f <31k-token-prompt> --temp 0 --seed 42 --single-turn --no-display-prompt
