# CONCLUSION: a CONSTANT ~70 MiB (53-88 MiB), independent of ubatch (512..8192), prompt length
# (602..68262 tokens), context size (16384..131072) and model (35B-A3B and Flash-Next both ~70).
# It does NOT scale, which rules out a per-call workspace: the hipBLASLt log shows the requested
# workspace is 0 / 12 KiB / 24 KiB / 64 KiB per call.  The constant is TensileLite code objects
# (one set per distinct solution; Flash-Next loads 27 shapes) plus a fixed small arena.
#
# So of a ~2 GiB headroom floor, hipBLASLt is ~70 MiB (~3.5 %).  The rest is the MTP draft
# buffer, the FA-QSA workspace, the workspace-pool high-water mark and the model's own
# PLE/attention allocations -- NOT hipBLASLt.  (ENVIRONMENT.md 'Why the cards sit near-full'
# lists hipBLASLt among those consumers; this measurement sizes it.)
